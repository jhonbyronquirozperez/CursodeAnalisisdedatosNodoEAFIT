Muchos datos no llegan en un archivo de Excel: llegan desde una API, casi siempre en formato JSON. En esta actividad vas a conseguir datos reales de una API pública y a convertirlos en un archivo CSV listo para analizar.

#### Qué debes hacer

1. Elige una API pública y gratuita. Algunas opciones: Open-Meteo (clima), Banco Mundial (indicadores por país), datos.gov.co (datos abiertos de Colombia), Rick and Morty API o PokeAPI.
2. Escribe una pregunta concreta que esos datos podrían responder.
3. Descarga los datos con Python o con Excel (Power Query) y guárdalos como CSV.

#### Qué entregas

- El archivo CSV, con el nombre `apellido_nombre_api.csv`.
- Un texto breve con: el nombre de la API, la URL que usaste, la fecha de descarga.
- Tu código, si usaste Python.
